# 小程序项目档案 · 刀塔集结（Dota2 战队赛）

> 码小序维护，每轮交付前更新。

## 项目概况
- 项目名：刀塔集结（dota2）
- 主体类型：待确认（个人/企业）
- AppID 环境：正式环境已配置（project.config.json）；云环境已配置（app.js，cloud1 环境）
- 定位：Dota2 玩家群比赛管理——报名 → 蛇形选人/系统分组 → TI 式双败赛程 → 结算归档

## 技术栈
- 微信原生开发，基础库 3.17.4
- 后端：微信云开发（云函数 dota2 + seasonPoints，wx-server-sdk ~2.4.0），无自建服务器
- 前端不直连数据库，全部经 `utils/api.js` 走云函数
- `lazyCodeLoading: requiredComponents` 已开启；自定义导航（nav-bar 组件，无 tabBar）
- dota2 云函数已模块化（2026-11-12）：index.js 只做路由，业务在 actions/ 与支撑模块

## 已用组件与接口
- 组件：nav-bar / player-card / tournament-flow / bracket-type-sheet
- 云函数动作：49 个（structure.test.js 锁定完整清单），入口 index.js 组装 actions/
- 云函数模块结构：db / constants / utils / cards / dota-profile / users / permissions / tournaments / auto-group / content-security / bracket-resolve / player-stats + actions/（bootstrap/home/profile/admin/tournament/registration/draft/bracket/grouping/test-tools/comments）
- 小程序工具模块：api / tournament-polling / date-time / roles / honors / dota-rank / team-logos / card-style / season-points-cache / share-text / poster
- UGC 内容安全：content-security.js（msgSecCheck v2 优先、v1 兜底、服务异常 fail-open），已接入 saveProfile（昵称+签名）/ setTeamName（队名）/ createTournament+updateConfig（名称+暗号）/ addComment（感言）

- 数据库集合：users / tournaments / config
