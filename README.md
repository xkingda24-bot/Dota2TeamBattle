# Dota2 战队赛 · 微信小程序

一个面向 Dota2 玩家群的比赛管理小程序：**报名 → 队长蛇形选人 → TI 国际邀请赛式双败赛程**，全流程自动管理，替代群内手记。

基于微信云开发（云函数 + 云数据库），无自建服务器。

## 功能特性

- **主页导航**：左上角「主页」一键回主页；右上角「管理员」查看管理员名单（所有用户可见）
- **多管理员体系**：首位初始化者成为最高管理员（超管），可添加/移除管理员；只有管理员可以创建比赛
- **创建比赛**：名称、日期时间、**报名暗号**、队长数量 N（2~16）、每队队友数 K（1~5）均可配置，支持同一天多场比赛并行
- **报名（需暗号）**：输入管理员设置的暗号验证通过后才能报名；队长 N 个、队员 N×K 个名额，满员锁定；可自行取消，管理员可移除
- **队长蛇形选人**：队长随机排序后按蛇形顺序轮流选人（1→N、N→1 往复共 K 轮）；严格轮流，上一个队长没选下一个不能选（服务端强制校验）
- **TI 双败赛程**：按队伍数自动生成与 Dota2 国际邀请赛一致的双败淘汰对阵（总决赛一场定冠军、无重置；非 2 的幂自动插轮空）
- **赛制配置**：每场比赛 BO1/BO3/BO5 仅管理员可配置
- **自动晋级淘汰**：管理员记录胜负后系统自动安排晋级/跌入败者组/淘汰；录错可修正（级联重置受影响场次）
- **历史比赛**：主页只显示今天创建的比赛；「历史比赛」页可查看之前比赛的过程与结果（名单、赛程、比分、冠军）

## 技术架构

```
小程序端（7 个页面）
   │  只调用云函数（不直连数据库）
   ▼
云函数 dota2（cloudfunctions/dota2）  ← 全部业务逻辑：权限/报名/选人/赛程/结果
   ▼
云数据库（自动创建 3 个集合）
   ├─ users         用户昵称（openid 免登录）
   ├─ tournaments   每场比赛全部数据
   └─ config        管理员名单（superAdmin + admins）
```

- 身份：微信 `openid` 自动登录，无需注册；普通用户仅需设置全局唯一昵称
- 数据：全部存储在微信云开发数据库（腾讯云托管），跨设备共享

## 目录结构

```
├─ miniprogram/                    小程序前端
│  ├─ app.js / app.json / app.wxss 全局配置（env 需填云环境 ID）
│  ├─ components/nav-bar/          自定义导航栏（主页/管理员入口）
│  ├─ pages/
│  │  ├─ index/    主页（创建入口 + 今日比赛 + 历史按钮）
│  │  ├─ create/   创建比赛（含暗号、N/K 配置）
│  │  ├─ register/ 报名（暗号验证 + 名单管理）
│  │  ├─ draft/    队长蛇形选人
│  │  ├─ bracket/  对战赛程（BO 配置/记录胜负/修正/归档）
│  │  ├─ history/  历史比赛（列表 + 详情）
│  │  └─ staff/    管理员名单（超管增删管理员）
│  └─ utils/api.js 云函数调用封装
├─ cloudfunctions/dota2/           云函数（后端）
│  ├─ index.js    全部业务动作
│  └─ bracket.js  TI 双败赛程生成器（N=2~16，含单测覆盖）
├─ project.config.json             项目配置（AppID 已填）
└─ uploadCloudFunction.sh          云函数部署脚本
```

## 部署步骤（约 5 分钟）

1. **导入项目**：微信开发者工具 → 导入项目 → 选择本目录（AppID 已配置）
2. **开通云开发**：工具栏「云开发」→ 创建环境，记下环境 ID
3. **配置环境 ID**：编辑 `miniprogram/app.js`，将 `env: ""` 改为你的环境 ID
4. **部署云函数**：右键 `cloudfunctions/dota2` → 上传并部署（云端安装依赖）；数据库集合首次调用自动创建
5. **初始化最高管理员**：群主第一时间打开小程序 → 右上角「管理员」→「初始化最高管理员」

> 详细步骤与使用流程见《使用说明_v2.md》（根目录）。

## 开发说明

- 全部业务逻辑在云函数内完成，前端不直连数据库，集合权限无需调整
- 双败赛程算法 `cloudfunctions/dota2/bracket.js` 有独立单测（N=2~16，787 项断言）
- 本机 `project.private.config.json`（微信开发者工具个人配置）已通过 `.gitignore` 排除，不入库
