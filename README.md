# Dota2 战队赛 · 微信小程序

一个面向 Dota2 玩家群的比赛管理小程序：**报名 → 队长蛇形选人 → TI 国际邀请赛式双败赛程**，全流程自动管理，替代群内手记。

基于微信云开发（云函数 + 云数据库），无自建服务器。

## 功能特性

- **报名与组队**：支持队长蛇形选人或天梯分与位置平衡的系统分组；支持队员、替补、队名和 Dota 风格队标
- **赛事管理**：配置比赛人数、赛制和报名暗号；生成 TI 风格双败赛程，自动晋级、记录比分、修正结果和归档
- **最终结算**：按赛果生成完整名次；未归档前比赛创建者或最高管理员可手动调整名次，参赛者及本场比赛创建者/最高管理员可发表或修改赛后感言
- **用户资料与名片**：可选验证 Dota 2 ID 并从 OpenDota 获取天梯分；设置 Dota 主题名片外观，赛事名单、队伍和结算均显示用户自定义名片
- **队标**：内置 25 款 Dota 主题 emoji，队长和组长可为队伍选择
- **比赛管理**：所有用户每天最多创建 2 场；比赛创建者和最高管理员可管理该场比赛，删除后不可恢复
- **历史比赛**：查看已归档赛事及完整比赛过程；历史详情只读
- **最高管理员**：由云函数环境变量指定的账号初始化；最高管理员可管理所有比赛并查看用户列表

## 技术架构

```
小程序端（多个业务页面）
   │  只调用云函数（不直连数据库）
   ▼
云函数 dota2（cloudfunctions/dota2）  ← 全部业务逻辑：权限/报名/选人/赛程/结果
   ▼
云数据库（`users` / `tournaments` / `config`）
   ├─ users         用户昵称（openid 免登录）
   ├─ tournaments   每场比赛全部数据
   └─ config        最高管理员身份与每日创建额度
```

- 身份：微信 `openid` 自动登录，无需注册；普通用户仅需设置全局唯一昵称
- 数据：全部存储在微信云开发数据库（腾讯云托管），跨设备共享

## 迁移副本验证与上线

1. **导入项目**：微信开发者工具导入 `D:\workspace\dota2-miniapp-migration`（AppID 已配置）。
2. **云环境**：`miniprogram/app.js` 已配置为现有环境 `cloud1-d0gvvih80af09b83d`，无需新建环境或改环境 ID。
3. **云函数**：本地 `cloudfunctions/dota2` 包含赛事所有者权限、每日创建额度、名片样式、结算名次、emoji 队标列表和赛后感言等动作。云端函数未更新前，这些新动作无法在云端使用。
4. **本地验证**：先在开发者工具编译并预览，再用测试赛事检查首页、每日创建额度、报名、选人、赛程/结算、历史、名片和用户列表。涉及新增云函数动作的流程需要部署函数后才能连云端验证。
5. **初始化数据库集合**：新云环境先部署 `dota2` 云函数，并在云函数管理界面配置 `INITIAL_SUPER_ADMIN_OPENID`。该账号首次打开小程序「我的」时，如果资料接口因集合缺失而失败，客户端会调用一次 `initializeDatabase` 创建三个集合并重试。集合已存在时不会影响数据；普通业务请求不再尝试创建集合。复用且已经有数据的环境无需重复初始化。
6. **最高管理员初始化**：已有最高管理员时无需操作；未初始化时，由配置的初始账号打开小程序并按「我的」页面提示完成初始化。成功后可清除 `INITIAL_SUPER_ADMIN_OPENID` 环境变量。
7. **上传版本**：本地验证通过后，在开发者工具上传小程序代码，再按微信公众平台的审核流程提交。

> 详细功能和使用流程见《使用说明_v3.md》（根目录）。

## 与 Web 版的迁移差异

- 微信 OpenID 负责用户身份，不再创建或重置独立密码账号；用户自行设置资料，超管身份由项目维护者指定。
- 队标使用 25 款内置 emoji，无需图片资源或云存储；历史记录继续通过稳定的队标 ID 映射到 emoji。
- Web 的单个虚拟测试队员注入入口未迁移；可通过正常报名流程验证比赛。

## 开发说明

- 全部业务逻辑在云函数内完成，前端不直连数据库；队标使用 emoji，名片装饰资源随小程序包发布
- 报名、选人、对战页面用轻量赛事版本接口轮询；完整赛事数据仅在版本变化或每两分钟同步一次时读取
- 主页赛事摘要和超管用户列表使用字段投影，避免读取赛程/对阵树及无关用户资料
- 数据库集合由初始最高管理员部署后一次创建，不在每次云函数调用时重复尝试创建
- 双败赛程算法 `cloudfunctions/dota2/bracket.js` 有独立单测（N=2~16）
- 本机 `project.private.config.json`（微信开发者工具个人配置）已通过 `.gitignore` 排除，不入库
