# Dota2 战队赛 · 微信小程序

一个面向 Dota2 玩家群的比赛管理小程序：**报名 → 队长蛇形选人 → TI 国际邀请赛式双败赛程**，全流程自动管理，替代群内手记。

基于微信云开发（云函数 + 云数据库），无自建服务器。

## 功能特性

- **报名与组队**：支持队长蛇形选人或天梯分与位置平衡的系统分组；支持队员、替补、队名和 Dota 风格队标
- **赛事管理**：配置比赛人数、赛制和报名暗号；生成 TI 风格双败赛程，自动晋级、记录比分、修正结果和归档
- **最终结算**：按赛果生成完整名次；未归档前管理员可手动调整名次，参赛者和管理员可发表或修改赛后感言
- **用户资料与名片**：可选验证 Dota 2 ID 并从 OpenDota 获取天梯分；设置 Dota 主题名片外观，赛事名单、队伍和结算均显示用户自定义名片
- **队标库**：内置 16 款离线可用队标；最高管理员可管理可选队标及顺序
- **回收站**：软删除比赛，可由管理员恢复或彻底删除
- **历史比赛**：查看已归档赛事及完整比赛过程；历史详情只读
- **管理员体系**：由云函数环境变量指定的账号初始化最高管理员；最高管理员可管理其他管理员

## 技术架构

```
小程序端（多个业务页面）
   │  只调用云函数（不直连数据库）
   ▼
云函数 dota2（cloudfunctions/dota2）  ← 全部业务逻辑：权限/报名/选人/赛程/结果
   ▼
云数据库（自动创建 3 个集合）
   ├─ users         用户昵称（openid 免登录）
   ├─ tournaments   每场比赛全部数据
   └─ config        管理员名单（superAdmin + admins）
```

- 身份：微信 `openid` 自动登录，无需注册；普通用户仅需设置全局唯一昵称
- 数据：全部存储在微信云开发数据库（腾讯云托管），跨设备共享

## 迁移副本验证与上线

1. **导入项目**：微信开发者工具导入 `D:\workspace\dota2-miniapp-migration`（AppID 已配置）。
2. **云环境**：`miniprogram/app.js` 已配置为现有环境 `cloud1-d0gvvih80af09b83d`，无需新建环境或改环境 ID。
3. **云函数**：本地 `cloudfunctions/dota2` 包含名片样式、结算名次、队标管理、回收站和赛后感言等动作。云端函数未更新前，这些新动作无法在云端使用。
4. **本地验证**：先在开发者工具编译并预览，再用测试赛事检查首页、创建、报名、选人、赛程/结算、历史、名片和管理员页面。涉及新增云函数动作的流程需要部署函数后才能连云端验证。
5. **管理员初始化**：复用环境会保留已有数据库记录。已有最高管理员时无需操作；未初始化时，维护者先在小程序「我的」复制指定账号的 OpenID，再在云函数 `dota2` 配置环境变量 `INITIAL_SUPER_ADMIN_OPENID`。刷新「我的」后，由该账号设置资料并完成初始化；成功后可清除该环境变量。
6. **上传版本**：本地验证通过后，在开发者工具上传小程序代码，再按微信公众平台的审核流程提交。

> 详细功能和使用流程见《使用说明_v3.md》（根目录）。

## 与 Web 版的迁移差异

- 微信 OpenID 负责用户身份，不再创建或重置独立密码账号；用户自行设置资料，超管管理管理员权限。
- 队标库提供 16 款内置图片，离线可用；自定义图片上传暂未接入，待云存储写权限和历史图片保留规则确认后再扩展。
- Web 的单个虚拟测试队员注入入口未迁移；可通过正常报名流程验证比赛。
